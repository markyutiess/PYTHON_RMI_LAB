\# Python RMI Lab using Pyro5



A Python-based distributed system demonstrating Remote Method Invocation (RMI) using Pyro5.



This project is an equivalent implementation of a Java RMI project translated to Python.



\## Project Structure



\- `product.py` — Remote interface / data definition (equivalent to `Product.java`)

\- `server.py` — Server implementation (equivalent to `Server.java`, `ProductImpl.java`, and `ServerImpl.java`)

\- `client.py` — Client application (equivalent to `Client.java`)



\## Prerequisites



\- Python 3.x

\- Pyro5 library
